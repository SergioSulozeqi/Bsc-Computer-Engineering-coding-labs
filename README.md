A curated collection of algorithms, data structures, and object-oriented programming labs developed during my BSc in Computer Engineering. 

This repository serves as a personal archive and a showcase of my fundamental computer science skills, focusing on **computational complexity (Big-O)**, **memory management**, and **efficient software design**.

---

## 📂 Repository Structure

The repository is divided into two main sections, reflecting the core university courses:

### 1. Fundamentals of Computer Science (`/Fondamenti_di_Informatica`)
**Language:** `Java`  
This section focuses on algorithmic thinking, Abstract Data Types (ADT), and Object-Oriented Programming principles.

*   **Algorithms & Complexity:** Implementation of recursive algorithms and asymptotic complexity analysis (Big-O) for both worst and average cases.
*   **Sorting & Searching:** Binary Search, Selection Sort, Insertion Sort, and Merge Sort.
*   **Data Structures:** Custom implementations from scratch of Arrays, Linked Lists, Stacks, Queues, Hash Tables, and Dictionaries.
*   **OOP Concepts:** Polymorphism, Inheritance, Interfaces, and Error handling.

### 2. Programming Laboratory (`/Laboratorio_di_Programmazione`)
**Language:** `C++`  
This section explores low-level memory management, efficient programming, and the use of the Standard Template Library.

*   **Memory Management:** Pointers, dynamic memory allocation, and lifecycle management.
*   **Object-Oriented C++:** Classes, scoping, and advanced control structures.
*   **Advanced Features:** Generic programming (Templates) and effective usage of the STL (Standard Template Library).
*   **Build & Execution:** Compilation, linking, and library creation processes.
